# Project Screenshots Directory

Place your project demonstration screenshots in this folder to include in your project report and viva presentation.

### Recommended Screenshots:
1. `01_gui_initial.png`: Main dashboard upon launching the application before starting the camera.
2. `02_camera_active.png`: Live camera stream showing the active screen boundary box and 0/30 FPS.
3. `03_hand_tracking.png`: Hand detected with 21 MediaPipe skeletal landmarks rendered.
4. `04_cursor_movement.png`: Index finger extended, moving the cursor across the desktop.
5. `05_left_click.png`: Index finger and thumb pinched together triggering a left click.
6. `06_right_click.png`: Middle finger and thumb pinched together triggering a context menu right click.
7. `07_double_click.png`: Ring finger and thumb pinched together opening an icon/folder.
8. `08_scrolling_mode.png`: Two fingers (index + middle) extended scrolling a webpage or document.
9. `09_control_paused.png`: Pressing 'P' to pause mouse control while maintaining tracking preview.
